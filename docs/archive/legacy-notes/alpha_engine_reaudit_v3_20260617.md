## 用户体验旅程验证

以一个典型用户场景为例检验完整链路：

### 场景："我想看 AAPL 现在该不该买"

```
1. 打开 Dashboard → 侧边栏 Core → Stock Terminal    ✅ 导航 2 步到位
2. 输入 "AAPL" → 搜索                                ✅ 基本操作
3. 看到 K 线图 + BUY 箭头标记                         ✅ R2 已实现
4. 看到价位线（买入区间、止损、目标）                   ✅ R2 已实现
5. 看到信号面板：BUY + 置信度 + 理由                   ✅ 原有能力
6. 看到推荐策略："DualLayer (因子丰富+低波动)"          ✅ T1.1 已实现
7. 看到价位详情：买入 185-190, 止损 178, 目标 205      ✅ T1.4 已实现
8. 看到数据新鲜度："Data: 3h ago"                      ✅ T2.5 已实现
9. 切到 Watchlist → 看到全市场信号 + 价格 + 涨跌幅     ✅ R3 基本实现
```

**这条核心链路已经基本打通。** 与初始检验时（纯 BUY/HOLD/SELL 文本 + 无价格 + 无策略推荐）相比，体验提升巨大。

### 仍断裂的链路

```
"这个信号已经持续多久了？"    → ❌ 无 signal_duration（R8 缺失）
"AAPL 适合哪些策略？对比一下" → ❌ 策略页面无对比功能（R6 缺失）
"因子具体是什么意思？"        → ❌ z-score 无文本解读（R14 缺失）
"SELL 信号的止损在哪？"       → ⚠️ K 线有线但侧边栏不显示（R9 部分）
```
