## 004. 记忆即身份：从“知识库”到 AI Agent 的职业人格

### 消失的昨日：失忆的专家

想象一个拥有世界顶级 IQ 的专家，他能瞬间解开最复杂的方程，却患有严重的“短期失忆症”——每隔五分钟，他的大脑就会清空一次。他不知道自己正在为谁工作，不记得上一个决策为什么失败，更无法在多次尝试中总结出你的偏好。

即便他拥有再强的计算能力，他也无法成为你的合伙人。他只能是一个一次性的计算工具。

在 AI Agent 的进化路径中，我们正在经历从“工具”向“职业人格”的惊险一跳。从 Manus 到 Claude Code，再到各种 OpenClaw 变体，AI 进化的模式已经非常清晰：**技能（Skills）正在变得模块化和插件化。**

技能赋予了 Agent “手”的能力。它们让 Agent 能够调用工具、执行代码、操作浏览器，在表面上表现出一个专业人员的称职。但真正定义一个 Agent 的能力边界、塑造其职业角色，并让它从一个通用工具进化为领域专家的核心要素，不是技能，而是**记忆（Memory）**。

如果说技能决定了一个 Agent **能做什么（What it can do）**，那么记忆决定了它在跨越任务时，是否还能保持**同一个职业自我（The same professional self）**。

### 逻辑的位移：从“图书馆”到“神经系统”

过去几年，B 端 AI 领域的主流叙事是：在企业知识库的基础上构建垂直领域的 AI 专家。然而在实践中，这种模式的效果往往差强人意。

随着长上下文（Long-context）模型的崛起，又出现了一种乐观的假设：如果上下文窗口足够大，检索能力足够强，模型就会自然地接近行业专家。

但回过头看，Agent 的真正升级并非仅仅是“记得更多”或“搜得更准”。真正的转折点在于一种逻辑的位移：**从“帮助模型知道更多”，转向“帮助 Agent 在任务链中保持同一个专业实体”。**

这类似于 Andrej Karpathy 所描述的 “LLM OS”：模型是内核（CPU），而记忆是状态（State）的延续。在 Agentic Workflow 中，记忆不再是像传统 RAG 那样冷冰冰的、等待被查询的被动数据库，它成为了 Agent **推理织物（Reasoning Fabric）**的一部分。

对一个 Agent 而言，真正有价值的记忆不是某篇文档的片段，而是**经验的可重用结构**：
- 它之前是如何做出判断的？
- 它为什么失败了？
- 它又是如何自我修正的？
- 哪些偏好和约束是必须贯穿始终的？

基础模型提供了通用的推理能力（Logic），而记忆提供了持久的专业状态（State）。前者决定了一个 Agent 能否像人一样思考，后者决定了它是否能持续地像**同一个专家**一样思考。

在这种架构下，**模块化是进化的阶梯**。技能被不断封装、抽象，而记忆则在模块的流转中沉淀为独特的职业人格。

技能让 Agent 行动；记忆让 Agent 知道自己是谁。

---

**Skills allow an agent to act; Memory allows it to know who it is.**
