## 执行结论

本次实验成功完成了用户要求中的第一部分：**找到更多真正独立的恢复事件。**

六组非 QQQ donor 资产共生成：

- 85 个不重叠资产事件；
- 31 个宏观日期簇；
- 六个 donor 资产；
- 最大单一资产事件占比仅 21.18%。

完整宏观簇留出 OOF 结果为：

- ROC AUC：**0.657**；
- Spearman IC：**0.238**；
- 顶／底概率四分位未来超额对数收益差：**+8.19%**；
- 六个 donor 中五个具有正向高低分层；
- 最大正向宏观簇贡献占比：20.82%。

因此 donor 独立事件与模型门槛全部通过。v4.11 的核心限制——只有少量 QQQ state-2 episode——在事件研究层面已经被克服。

但是第二部分没有完成：**冻结的 SGOV/TQQQ 迁移策略没有击败 v4.2。**

最终分类：

`sgov_tqqq_transfer_does_not_stably_beat_v4_2`

独立审计分类：

`audit_pass_nonpromotion_result_valid`

失败不是 donor 模型完全无效，而是发生在两个后续环节：

1. donor 概率不能直接跨资产迁移到 QQQ 的少量恢复事件；
2. 用一个简单 structural regime 全面替换 v4.2 状态机过于防守，丢失了 v4.2 的主要收益路径。

因此：

- v4.2 继续作为唯一行动性研究基线和 Telegram 权重来源；
- v4.12 不进入 shadow challenger；
- 不允许根据四个 QQQ 事件反转概率、改阈值或重做特征；
- donor 独立事件库与 cluster OOF 框架保留，作为后续更窄、更合理的 state-2 风险预算研究基础。

## 1. 独立性设计

模型训练完全排除：

- QQQ；
- TQQQ；
- QQQI；
- SGOV；
- VXN。

训练 donor 固定为：

| Underlying | 3x ETF |
|---|---|
| SPY | UPRO |
| IWM | TNA |
| DIA | UDOW |
| XLK | TECL |
| SOXX | SOXL |
| XLF | FAS |

BIL 仅作为 donor 长历史现金代理。QQQ/TQQQ 只在模型冻结后用于目标评估，SGOV 不做成立前回填。

每个资产的事件必须：

- 始于 63 日回撤达到 -10% 的冲击周期；
- 在价格恢复至 MA20 之上、MA20 五日斜率转正且 VIX 从20日高位回落至少15%时触发；
- 每个冲击周期只允许一个事件；
- 最长持有20个交易日；
- MA20下方连续两日或VIX进入压力状态时提前结束；
- 同一资产事件不得重叠。

不同资产的事件若在30个自然日内启动，归入同一 `macro_cluster_id`。OOF 验证每次完整留出一个宏观簇，避免同一次2020式冲击在训练与验证中同时出现。

## 6. 为什么策略失败

### 6.1 事件扩充与目标迁移是两个不同问题

85个 donor 事件解决了训练样本不足，但没有自动解决 QQQ 的资产域差异。模型在 cluster 维度具有稳定性，却没有经过完整 leave-one-asset-out 验证。

### 6.2 Structural regime过度防守

实际产品期内，structural策略平均TQQQ权重仅11.87%，84.18%的时间处于100% SGOV。v4.2 的收益不仅来自少量深度冲击后的恢复，还来自 state 1桥接和正式 state 2参与。全面替换状态机切断了主要收益来源。

### 6.3 Event override没有实际产品事件

四个目标事件全部发生于2020—2022。实际 QQQI 同窗中无事件，因此 joint 无法检验 donor 模型，只检验了 structural rule。

### 6.4 简单静态杠铃仍不够

实际期内静态50/50 SGOV/TQQQ的CAGR达到29.51%，接近v4.2，但最大回撤扩大至-34.95%。这说明SGOV/TQQQ本身具备收益潜力，问题在于需要更精确地控制**何时增加杠杆**，而不是简单长期混合。

## 8. 当前研究决策

保留：

- 跨资产独立事件库；
- 非重叠冲击周期定义；
- 宏观簇完整留出框架；
- donor OOF 模型与证据；
- SGOV/TQQQ精确同窗执行框架。

拒绝：

- 用 generic donor 恢复概率直接映射 QQQ；
- 用当前 structural rule 全面替换 v4.2；
- 根据四个 QQQ 事件反转概率；
- 搜索0.45/0.60阈值；
- 搜索0%/50%/75%/100%权重；
- 放宽 donor 或策略门槛。

下一条可接受路线必须同时满足：

1. 在 donor 端增加 leave-one-asset-out transfer gate；
2. 保留 v4.2 的 state 0和state 1，不再全面替换收益路径；
3. 只在 formal state 2 内研究 SGOV/TQQQ 风险预算；
4. 使用未被本实验查看的目标时期或前瞻事件作为主要验证，而不是重新利用2020—2022四个事件。
