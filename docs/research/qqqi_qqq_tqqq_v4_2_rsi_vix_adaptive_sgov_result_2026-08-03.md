## 执行结论

本次实验不支持把 RSI × VIX 自适应 SGOV 方案升级为新的 v4.2 替代模型，也不支持建立行动性 shadow signal。

最终实验分类：

`benefit_not_chronologically_stable`

独立审计分类：

`audit_pass_nonpromotion_result_valid`

联合方案确实降低了损失深度，但没有在保留 v4.2 复利能力的同时形成稳定优势：

1. 最大回撤由 -24.22% 改善至 -18.60%，改善约 **5.63 个百分点**；
2. CAGR 由 33.58% 降至 29.10%，牺牲约 **4.48 个百分点**，超过预注册的 2 个百分点上限；
3. 早期样本 Calmar 改善，但后期样本 Calmar 从 v4.2 的 3.618 降至 2.747；
4. 长历史 QQQ 代理中，联合方案反而弱于 RSI-only，说明短样本优势不是稳定的结构性 RSI×VIX 交互效应。

因此：

- v4.2 继续作为当前唯一研究基线和现有提醒来源；
- RSI × VIX 联合方案不进入 shadow challenger；
- 静态 QQQI/SGOV 结构继续只作为低回撤风险偏好画像；
- Telegram、目标权重和 Issue #348 均保持不变；
- 不允许在当前样本继续搜索 RSI 周期、阈值、确认长度或 SGOV 权重。

## 1. 冻结研究设计

研究问题：RSI 能否与 VIX 共同控制 SGOV 的进入和释放，使模型既能降低下跌损失，又避免静态 SGOV 长期占用造成的复苏拖延？

冻结规则：

- 指标：QQQ Wilder RSI(14)；
- 联合激活：RSI 严格低于 45，且现有 v4.2 VIX 状态为 stress/spike；
- 联合释放：RSI 严格高于 50，连续两个有效收盘，同时 VIX easing 或 normalized；
- 收盘生成信号，下一交易日开盘执行；
- 每单位换手成本 10 bps；
- state 0 激活时：50% QQQI / 50% SGOV；
- state 1 激活时：25% QQQI / 50% QQQ / 25% SGOV；
- state 2 始终保持 25% QQQ / 75% TQQQ；
- 不搜索任何参数。

五组比较对象：

1. 当前 v4.2；
2. 静态 blended QQQI/SGOV；
3. VIX-only 自适应 SGOV；
4. RSI-only 自适应 SGOV；
5. RSI × VIX 联合自适应 SGOV。

- 正相对收益事件：3 个；
- 负相对收益事件：7 个；
- episode 正收益率：30%；

- 负贡献总和约 -10.85%；
- 最大正贡献事件占全部正贡献的 57.2%。

主要正贡献：

- 2024-07-22 至 2024-08-14：相对 v4.2 +1.08%；
- 2025-02-25 至 2025-05-12：+1.73%；
- 2026-02-06 至 2026-04-09：+0.21%。

主要负贡献：

- 2026-06-11 至 2026-06-12：-2.46%；
- 2025-01-13 至 2025-01-21：-2.27%；
- 2024-11-01 至 2024-11-06：-1.67%。

联合机制能在少数持续压力阶段提供保护，但激活后仍有较高概率遇到快速修复或没有形成实质回撤，从而错失上涨。

最终 artifact 已把 episode 字段明确拆分为：

- `activation_signal_date`；
- `execution_date`；
- `signal_rsi_14`；
- `signal_vix_close`；
- `release_signal_date`；
- `release_execution_date`；
- release signal-close RSI/VIX。

因此信号时点与执行时点不再混用。

## 12. 最终研究决策

本次负面推广结论有效：

- RSI 与 VIX 联合使用具有一定实际样本风险控制价值；
- RSI 明显改善了单独依赖 VIX 的方案；
- 但联合方案没有保留足够的 v4.2 复利能力；
- 联合方案未超过静态 SGOV 风险画像；
- 长历史代理不支持其相对 RSI-only 的结构性优势；
- 不应继续在当前样本上搜索参数。

允许的下一步仅为：

1. 合并本次可复现的实验基础设施、负面/混合证据和报告；
2. 在未来前瞻事件中只记录冻结的 RSI/VIX 特征，不改变行动性权重；
3. v4.2 继续保持不变。
