# BYD V1.0：单标的中频基准研究

## 1. 为什么需要独立的单标的模型

AlphaEngine 的 CN x1.0 解决的是固定股票池中的横截面排序问题：在同一个调仓日比较多只股票，选择相对更强的标的。BYD V1.0 解决的是另一类问题：仅面对比亚迪 `002594.SZ`，判断下一交易日开盘后应持有比亚迪还是现金。

因此，BYD V1.0 不是把 CN x1.0 缩小到一个样本，也不使用单股票无法定义的 Rank IC、Top-N 或 Bottom-N。它采用时间序列状态、下一开盘执行、买入持有对照和逐笔交易归因。

## 2. 首版研究范围

V1.0 只允许：

- 日频前复权 OHLCV；
- 收盘后生成信号；
- 下一交易日开盘切换 `BYD / CASH`；
- 长仓或空仓，不做空、不融资、不使用杠杆；
- 五个事先冻结、具有明确经济含义的中频规则；
- 10、20、40 bps 成本压力测试；
- 2012—2024 年选择证据与 2025 年以后一次性隔离检查。

首版不加入沪深300状态过滤、汽车行业相对强弱、财报事件、新闻、机器学习、盘中止损或 BYD 港股。这些因素可能有价值，但若与首轮技术规则同时进入，就无法判断收益究竟来自哪一类信息。

## 3. 候选策略

| 候选 | 核心逻辑 | 主要风险 |
| --- | --- | --- |
| `trend_20_60` | 中短期趋势同向时持有，短趋势破坏时退出 | 震荡期反复进出 |
| `breakout_55_20` | 突破过去 55 日高点后持有，跌破 20 日低点退出 | 突破失败与跳空成本 |
| `momentum_20_120` | 长期趋势向上且 20 日动量为正时持有 | 高位动量反转 |
| `rsi_trend_reversion` | 长期趋势向上时买入 RSI 回撤，修复后退出 | 强下跌中“接飞刀” |
| `bollinger_trend_reversion` | 长期趋势向上时买入下轨偏离，回归均线后退出 | 波动扩张使下轨持续下移 |

所有滚动最高价和最低价均使用 `shift(1)`，当前收盘只能与此前已经完成的窗口比较。信号在收盘形成，仓位在下一开盘生效。

## 4. 选择与隔离

候选只能使用 2012-01-01 至 2024-12-31 的证据进行一次选择。选择目标不是最高历史收益，而是同时满足：

- Calmar 高于买入持有；
- 回撤或 Sortino 有明确改善；
- CAGR 不出现不可接受的牺牲；
- 多数年度具有相对有效性；
- 换手和年度贡献不过度集中；
- 40 bps 成本与移除最佳交易后仍成立。

2025-01-01 至 2026-08-03 为固定隔离期。该区间只能用于否证，不能用于修改均线、RSI、布林带、突破窗口或成本。只有选择门槛和隔离门槛同时通过，获胜规则才可命名为 BYD V1.0。

## 5. 数据供应商纪律

自动证据运行采用预先冻结的顺序：BaoStock 前复权完整历史优先，AkShare/Eastmoney 前复权完整历史次之。这个顺序仅解决供应商技术可用性，不依据任何策略结果选择。

一次运行必须从首日至 `2026-08-03` 全部使用同一个供应商。禁止把两个供应商的区间拼接，也禁止在结果已知后按收益选择数据源。manifest 会记录每次供应商尝试、最终采用者、接口、复权方式、首末日期、行数和 SHA-256。

## 6. 输出

运行命令：

```bash
uv run python scripts/run_byd_v1_0.py \
  --fetch-provider auto \
  --output-dir artifacts/research/byd_v1_0
```

输出包括：

- `summary.json`：最终决定、门槛、当前仓位和最新收盘信号；
- `candidate_summary.csv`：五个候选的发展/验证指标；
- `selected_daily.csv`：获选候选每日信号、仓位、收益、成本与回撤；
- `selected_trades.csv`：逐笔交易；
- `byd_ohlcv.csv`：本次运行实际使用的数据；
- `report.md`：面向人工审阅的研究报告；
- `data_blocked.json`：所有冻结供应商均失败时的显式阻塞证据。

若 `2026-08-03` 数据不存在，运行失败为 `data_blocked`，不使用较旧数据冒充最新基准。

## 7. 版本结论

本研究首先建立的是**单标的研究范式**。即便历史门槛通过，BYD V1.0 仍保持 `research_only=true`、`trade_ready=false`。后续只有在固定规则下积累前瞻信号与执行证据，才可讨论是否进入影子运行。
