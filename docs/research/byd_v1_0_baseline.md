# BYD V1.0：单标的规则基线

> **定位纠正：**BYD V1.0 不是 XGBoost 模型，也没有在长期总收益或 CAGR 上跑赢比亚迪买入持有。它只证明了一个低换手的 75%/100% 规则可以略微改善回撤与 Calmar。因此，V1.0 的正式身份是 `rule_baseline`，不能被描述为已经找到“适合比亚迪、获取最大利益”的专有模型。Issue #503 将以动量因子研究和 walk-forward XGBoost 建立真正的 BYD V1.1 候选。

## 1. 模型类型

AlphaEngine 的 CN x1.0 是横截面模型：在固定股票池中比较不同股票。BYD V1.0 是单标的时间序列**规则基线**：只面对比亚迪 A 股 `002594.SZ`，在每个交易日收盘后决定下一交易日开盘的目标仓位。

因此，BYD V1.0 不使用单股票无法定义的 Rank IC、Top-N 或 Bottom-N，而使用：

- 单标的状态信号；
- 下一交易日开盘执行；
- 买入持有比亚迪作为主基准；
- 交易成本、最大回撤、Calmar、收益保留率和防御阶段贡献。

## 2. 第一阶段：纯二元择时被否决

首轮冻结并比较了五个 `BYD / CASH` 二元策略：

- `trend_20_60`；
- `breakout_55_20`；
- `momentum_20_120`；
- `rsi_trend_reversion`；
- `bollinger_trend_reversion`。

真实数据证据结论为 `byd_v1_0_not_supported`。这些策略普遍因长期空仓错过比亚迪主升段，2012–2024 CAGR 明显低于买入持有；多个候选在 2023–2024 固定验证期转为负收益。继续扫描 RSI、均线或突破窗口只会增加过拟合风险。

这项负结果被保留为正式证据，而不是从报告中删除。

## 3. 第二阶段：核心仓位 + 战术仓位

基于第一阶段结论，BYD V1.0 改为：

- 永久保留 75% 比亚迪核心仓位；
- 仅使用 25% 战术仓位进行中频防御；
- 满仓状态为 100% 比亚迪；
- 防御状态为 75% 比亚迪、25% 现金；
- 不做空、不融资、不使用杠杆或盘中止损。

冻结的七个候选覆盖：

- 长期趋势 + 动量滞回；
- SMA60/SMA200 长期状态；
- 252 日高点回撤防御；
- 50% 与 75% 核心仓位；
- 无滞回的动量对照。

## 4. BYD V1.0 规则基线

唯一通过原规则型风险调整门槛的候选为：

`core75_regime_mom_120`

收盘时计算状态：

- **进入满仓状态**：收盘价高于 SMA120，且 20 日动量为正；
- **进入防御状态**：收盘价低于 SMA120，且 60 日动量为负；
- **满仓状态**：100% 比亚迪；
- **防御状态**：75% 比亚迪、25% 现金；
- **执行**：信号形成后的下一交易日开盘。

进入和退出条件并不对称，这是有意设置的滞回机制：普通回调不会立即触发减仓，只有长期趋势与中期动量同时转弱时，才关闭 25% 战术仓位。

## 6. 数据与成本纪律

- 证据截止：`2026-08-03`；
- 数据范围：`2011-06-30` 至 `2026-08-03`；
- 接受供应商：Yahoo 自动复权完整历史；
- OHLCV SHA-256：`84365ce1549b8a598fbf965c5033f61f80a30decf14b316061c0af218d7f1234`；
- 主成本：每单位仓位变化 20 bps；
- 压力成本：40 bps；
- 40 bps 下 2012–2024 总收益仍为 1,014.91%；
- 禁止跨供应商拼接、缺失前填和同日收盘成交。

自动数据顺序为 BaoStock、AkShare/Eastmoney、Yahoo。每次运行只能接受一个供应商的完整历史，并记录全部尝试。此次 BaoStock 和 AkShare 在 GitHub 托管运行器上失败，最终整段历史均来自 Yahoo。
