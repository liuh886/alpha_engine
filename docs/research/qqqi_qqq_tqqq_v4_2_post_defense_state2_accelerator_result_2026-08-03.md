## 执行结论

本次实验获得了一个比单独 RSI×VIX 防守明显更接近“回撤保护 + 上涨修复”的组合，但仍不支持把它升级为新的行动性模型，也不支持立即替代 v4.2。

最终实验分类：

`accelerator_not_chronologically_stable`

独立审计分类：

`audit_pass_nonpromotion_result_valid`

组合方案取得了三个实质性改善：

1. 相比单独 RSI×VIX 防守，CAGR 从 **29.10%** 恢复至 **32.68%**，收回约 **80.1%** 的防守收益损失；
2. 相比当前 v4.2，CAGR 只低 **0.89 个百分点**，同时最大回撤由 **-24.22%** 改善至 **-19.11%**；
3. Calmar 从 v4.2 的 **1.386** 提升至 **1.710**，最长水下期从防守模型的 229 个交易日缩短至 118 个交易日。

但三个预注册门槛未通过：

- 后期样本 Calmar 为 **3.350**，低于 v4.2 的 **3.618**；
- 最大正贡献 episode 占全部正贡献约 **90.0%**，远高于 50% 上限；
- 换手为 70.0，较 v4.2 增加 **27.3%**，略高于 25% 上限。

因此：

- v4.2 继续作为唯一行动性研究基线和 Telegram 权重来源；
- 本候选不进入行动性模型，也不改变 Issue #348；
- 100% TQQQ 加速不应继续在当前样本上搜索权重、期限、延迟或退出条件；
- 可以把本实验作为一个有机制价值但尚未获得独立事件支持的冻结研究候选保存。

## 1. 与上一个实验的连续性

上一轮实验已经确认：

- RSI×VIX 防守可把最大回撤从 -24.22% 降至 -18.60%；
- 但 CAGR 从 33.58% 降至 29.10%；
- 主要问题不是防守无效，而是防守期间和释放后的风险暴露不足，造成上涨机会成本；
- 不能通过继续调整 RSI、VIX、SGOV 阈值来挽救结果。

本轮因此没有重写防守规则，只增加一个单独、可证伪的风险预算再部署层。

### 冻结防守规则

完全复用 PR #467：

- QQQ Wilder RSI(14)；
- RSI <45 且现有 VIX context 为 stress 时激活；
- RSI >50 连续两个收盘且 VIX easing/normalized 时释放；
- state 0 防守：50% QQQI / 50% SGOV；
- state 1 防守：25% QQQI / 50% QQQ / 25% SGOV；
- 收盘形成信号，下一交易日开盘执行。

### 冻结加速规则

- 一次完整防守释放后，武装一次加速机会；
- 只等待原始 v4.2 状态机正式执行 state 2；
- 第一个连续 state 2 episode 从 25% QQQ / 75% TQQQ 改为 **100% TQQQ**；
- 离开 state 2 或新的防守激活后立即结束；
- 该机会在进入首个 state 2 时即被消耗；
- 后续 state 2 保持普通 v4.2，直到下一次完整防守结束；
- 不使用 precursor、不增加延迟、不搜索 80%/90% 权重或持有期限。

- 额外 25% TQQQ 在这些正式 state 2 episode 中总体创造了收益；
- 单独增加杠杆并不能提供回撤保护；
- RSI×VIX/SGOV 防守层确实承担了风险缓冲作用；
- 组合方案的风险收益改善来自“先防守、后正式确认加速”，而不是单纯提高 TQQQ。

## 11. 独立审计

审计从最终 artifact 的 daily return、权重、trace、episode CSV 和 manifest 重新计算，而不是直接采用生成报告的判断。

已确认：

- 四个模型逐日 `position_state` 与 v4.2 完全一致；
- tag-only 和 combined 使用完全相同的 61 个实际加速日；
- 所有加速日的执行状态均严格为 state 2；
- 加速日逐日为 100% TQQQ，QQQ/QQQI/SGOV 均为 0；
- 非加速 state 2 仍为 25% QQQ / 75% TQQQ；
- 每日权重之和严格等于 1；
- 交易成本逐日等于换手乘以 10 bps；

- 实际样本 9 次防守释放中只有 5 次在新的防守激活或样本结束前进入 state 2，恰好对应 5 个加速 episode；
- 代理样本 11 个加速 episode 的日期也与 arm/consume 状态机逐一匹配；
- evidence manifest 共声明 33 个文件，SHA-256 全部匹配；
- 独立复算的总收益、CAGR、最大回撤和 Calmar与 headline 表一致。

## 12. 最终研究决策

本次实验比上一轮更有价值，也更接近可用候选：

- 防守层确实保留了大型回撤保护；
- 正式 state 2 后的额外 TQQQ 确实显著恢复 CAGR；
- 实际与代理样本都支持加速相对防守模型的收益和 Calmar方向；
- 组合方案已经把 v4.2 的 CAGR 差距压缩到 0.89 pp，同时保留 5.12 pp 最大回撤改善。

但当前证据仍不能支持晋级：

- 实际增量收益高度集中于一个 2026 年强反弹 episode；
- 后期 Calmar 仍低于 v4.2；
- 换手略超预注册上限；
- 2026 年未解决回撤仍显示状态失配风险。

因此允许的下一步仅为：

1. 合并本次冻结实现、实际/代理证据、事件归因和负面晋级结论；
2. 保留 v4.2 为唯一行动性基线，不修改 Telegram；
3. 在未来真实防守后 state 2 episode 中前瞻记录该冻结候选；
4. 在新增多个独立 episode、并显著降低 2026 单事件贡献占比之前，不重新讨论权重、期限或推广。
