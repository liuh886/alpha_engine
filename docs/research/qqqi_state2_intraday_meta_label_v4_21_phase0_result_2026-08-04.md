# QQQI / QQQ / TQQQ v4.21 日内 Meta-label Phase 0 结果

**证据日期：** 2026-08-04  
**研究状态：** research-only；not trade-ready  
**当前基准：** `qqqi_qqq_tqqq_vxn_bridge_v4_2`  
**结论：** `intraday_phase0_failed_no_outcomes_authorized`

## 1. 研究动机

v4.14–v4.20 已经反复证明，继续在日线 VIX、VXN、RSI20、Bollinger、QQQ/VOO 和信用久期因子上构造覆盖式资产配置，难以稳定超越 v4.2。与此同时，既有 state-2 尾部审计显示：最差杠杆日的主要损失在交易日内形成，前一收盘没有可用预警。

因此，v4.21 不再替代 v4.2，而是提出两层架构：

1. v4.2 继续负责慢速日线状态；
2. 仅在冻结 state 2 日，使用开盘后 30 分钟的新信息判断是否将剩余时段从 `25% QQQ / 75% TQQQ` 临时降至 `100% QQQ`。

Phase 0 只验证日内数据是否足以支持独立开发和隔离验证，不计算任何标签、模型或策略结果。

## 2. 数据与适配器治理

本轮建立了 Polygon 30 分钟聚合数据适配器，并要求：

- 聚合响应中的 ticker 必须与请求标的一致；
- 所有 `next_url` 必须完整翻页；
- 跨页重复时间戳直接拒绝；
- UTC 时间戳与 `America/New_York` 本地时间同时保留；
- 只保留 09:30–16:00 常规交易时段；
- 夏令时和冬令时的 09:30 开盘栏必须一致识别；
- 标的之间和分页之间主动限速；
- 不允许用 Yahoo 近期日内数据或合成数据回填。

日线 v4.2 路径使用专用 open/close 研究适配器重建。该适配器保留 Yahoo 调整后 open、close 和 volume，只为模式校验合成 `high=max(open, close)`、`low=min(open, close)`；合成 high/low 明确禁止用于波动率、区间或日内特征。

## 4. 冻结 state-2 人群

- 2018–2023 开发期可用 state-2 日：**0**；
- 2024-08-05 至 2026-08-03 实际期可用 state-2 日：**129**；
- state-2 权重核验：`0% QQQI / 25% QQQ / 75% TQQQ`，通过；
- 实际期最早可用 state-2 日：2024-08-22。

Phase 0 预注册门槛要求至少三个完整开发年度、150 个开发 state-2 日和 60 个隔离实际期 state-2 日。实际期数量通过，但开发期完全缺失。

## 5. 决策

本轮不能计算日内 overlay 标签，也不能训练 meta-label 模型：

- 不能把 129 个实际期事件同时作为训练样本和独立验证；
- 不能在看到覆盖后把 2024+ 从隔离窗口改成可晋级开发窗口；
- 不能缩短历史请求、改用近期 Yahoo 日内数据或合成早期日内数据；
- 不能由 Phase 0 结果修改 v4.2、Telegram 或 Issue #348。

正式结论为：

`intraday_phase0_failed_no_outcomes_authorized`

这不是对日内 tail overlay 机制的否定，而是数据覆盖不支持原定的独立历史检验。

## 6. 后续研究边界

允许保留两个不同层级的后续工作：

1. **可行性试验：** 在现有 2024-08 至 2026-08 数据上，按预先冻结的时间切分评估十项因子是否存在基本排序信号。该试验不得授权 shadow、提醒或策略修改，只能决定该机制是否值得持续积累数据。
2. **正式验证：** 继续积累 Polygon 日内数据，或获得具备更长历史权限的独立专业数据源。只有新的、未参与试验设计的前瞻事件才能支持 shadow 候选。

不得继续搜索开盘窗口长度、模型、特征子集、分位阈值、止损方式或连续杠杆权重。
