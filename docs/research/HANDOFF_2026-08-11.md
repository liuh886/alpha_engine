## 零、基础设施架构（新增）

### 模型优化器 (`src/optimization/`)

声明式实验框架，任何 agent 通过 YAML 规格即可运行优化实验。

| 组件 | 文件 | 用途 |
|---|---|---|
| 实验合约 | `contracts.py` | ExperimentContract, CandidateSpec, CostStructure, WindowSpec |
| 统一门控 | `metrics.py` | 6 门控自动检查 + 复合指标计算 |
| 运行器基类 | `runner.py` | BaseOptimizationRunner — 完整实验生命周期 |
| Ranker 优化器 | `ranker_runner.py` | 横截面排序器 (USx/CNx)，含 sector cap + guardrail |
| Rotator 优化器 | `rotator_runner.py` | ETF 轮动优化器 (QQQR)，状态权重 + panic repair |
| Timer 优化器 | `timer_runner.py` | 单股择时优化器 (BYD)，凸动量预算 |
| 收据生成 | `receipts.py` | JSON + Markdown 双格式，版本化身份绑定 |

```
# 任何 agent，3 步运行
python scripts/run_model_optimizer.py --spec configs/optimization/my_grid.yaml
# → artifacts/optimization/{id}/experiment_receipt.json
```

### 统一数据层 (`src/data/foundation.py`)

线上线下共享的 DataFoundation。同一代码路径服务回测和实盘。

```
from src.data.foundation import DataFoundation

foundation = DataFoundation(market="us", benchmark="QQQ")
foundation.initialize()

# 离线优化
wdata = foundation.load_window("2024H1", exprs)

# 在线 forward walking
latest = foundation.load_forward_window(exprs, lookback_sessions=500)

# 数据刷新检测（对齐线上 CSV → Qlib binary 管线）
if foundation.needs_refresh():
    foundation.refresh()
```

| 能力 | 说明 |
|---|---|
| Provider 身份检测 | `needs_refresh()` 对比 manifest SHA256 |
| 自动缓存失效 | Provider 更新 → 清空缓存 → 重初始化 |
| 审计追踪 | `initialized_at`, `last_refresh_time` |
| 行业分类 | `sector_map` — US87 + CN130 |
| 窗口管理 | `load_window()` / `load_forward_window()` / `train_test_split()` |
| 因子库集成 | `factor_library` 属性 → 307 因子 |

## 一、US x1.1 → US x1.2 推荐

### 当前基线
- 模型: XGBoost rank:ndcg, 7 OHLCV 因子, Top-15 等权, 10D horizon
- 超额: +99.9%, 回撤: -28.4%, IC: 0.045, 基准: QQQ

### 优化历程
| 轮次 | 实验 | 关键发现 |
|---|---|---|
| R1 | XGBoost 校准网格 (6种) | row_and_column_sampling 超额 +10pp, 回撤不变 |
| R2 | 因子扩展 (risk_ctrl) | 超额 +131.7%, 回撤仍不通过 |
| R3 | 行业上限集成实验 | **突破**: max-4-names/sector 通过回撤门 (+5.5pp) |
| R4-10 | 多维度网格 (300评估) | 11候选通过全部门控, Top-15+cap=4 最佳 |
| R11-15 | 扩展校准+新因子+2026H1 | lower_lr(300r,lr=0.03) 最优, 2026H1 +48.9% |

### 最终推荐
```
首选: r11_lower_lr + Top-15 + max-4-names-per-sector
- 7 OHLCV 因子 (momentum_volatility_volume)
- XGBoost: 300轮, lr=0.03, subsample=0.8, colsample_bytree=0.8
- 复合超额: +227.9% (vs 基线 +99.9%, +128pp)
- 最差回撤: -24.6% (vs 基线 -28.4%, +3.8pp)
- 2026H1验证: +48.9% 超额

保守 (优先回撤): r12_mvv_rev_meanrev + Top-15 + cap=3
- 13因子 (+reversal +mean_reversion), 回撤 -23.2% (+5.2pp)
- 超额 +185.4%

关键设计模式:
- max-4-names-per-sector 是回撤门通过的充要条件
- lower_lr (lr=0.03, 300轮) 在US/CN市场均最优
- 行业上限比增加因子更有效
```

| R1-10 | 分配权重扫描 | **defense=BYD 0% 全面碾压** |
| R11-25 | 凸动量+阈值扫描 | 参数变化影响小 |
| R26-30 | 组合测试 | 简单规则 > 复杂状态机 |

```
首选: R3_def0_off100 (极度简单)
- 规则: mom_20 > 0 → BYD 100%, else → 515180 100%
- Defense: BYD 0% + 515180 100% (vs 当前 BYD 75% + 515180 25%)

                     v1.2     v1.3      R3
  Total Return      5.9x      6.3x     98.1x

recovery lifecycle) 实际在损害性能。简单的 mom_20 > 0 规则远超它们。
```

## 跨模型设计模式总结

### 普遍真理
1. **lower_lr (lr=0.03, 300轮) 在 US/CN 市场均最优** — XGBoost 训练
2. **简单规则 > 复杂状态机** — BYD 证明了 mom_20 单因子碾压 v1.3 复杂状态机
3. **集中度约束改善回撤** — US 行业上限, CN 3行业, QQQR SGOV 缓冲
4. **防御时增加现金/ETF缓冲** — BYD 和 QQQR 的核心改进
5. **参数优化 > 添加因子** — 校准调优的回报超过新因子

### 市场特殊性
- **US**: 行业上限 (max-4/sector) 是关键, 价格+量因子足够
- **CN**: Price_pressure 因子 (ret×volume) 适合 A股, 真实行业分类重要
- **QQQR**: 防御状态加 SGOV 是突破性改进, panic boost 有害
- **BYD**: 简单动量规则碾压所有复杂状态机

### 成本一致性
- USx: 20bps (标准)
- CNx: 20bps (标准)  
- QQQR: 10bps (ETF 低成本)
- BYD: 20bps (单股标准)

所有优化均保持原模型成本结构不变。
